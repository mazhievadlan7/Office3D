# Ключи для «Глаз Бога» — реализм максимального уровня

Всё в ГЕО работает без ключей (Esri World Imagery + offline Natural Earth +
дюжина публичных живых слоёв). Эти два ключа добавляют верхний тир реализма:
мировой рельеф и фотореалистичные 3D-здания.

Оба — бесплатные, запрашиваются один раз, подставляются в `.env`.

## 1. Cesium Ion — мировой рельеф + базовые имиджериз

Что даёт: Cesium World Terrain (3D-карта с высотами) + World Imagery
(спутниковая мозаика Bing/Maxar). После установки ключа кнопка **РЕАЛИЗМ**
в правом нижнем углу ГЕО переключает на этот тир.

1. Регистрация: <https://ion.cesium.com/signup> — бесплатный аккаунт.
2. Токены: <https://ion.cesium.com/tokens>. Готовый `Default Token` можно
   скопировать сразу, либо создать новый.
3. В `.env`:
   ```env
   NEXT_PUBLIC_CESIUM_ION_TOKEN=eyJhbGciOi...
   ```
4. Пересобрать (NEXT_PUBLIC_* применяется на этапе build):
   ```bash
   npm run build && npm start
   ```

Бесплатный лимит: ~5 ГБ трафика / месяц для некоммерческого использования —
хватит с запасом на штаб из нескольких человек.

## 2. Google Photorealistic 3D Tiles — фотореалистичные здания всего мира

Что даёт: честный 3D-город (все застроенные регионы Земли). Это то, что
источник проекта gods-eye-view называет «photoreal». Приоритет выше Cesium
Ion: при установленном Google-ключе РЕАЛИЗМ использует его.

1. Google Cloud Console: <https://console.cloud.google.com>
2. Создать (или выбрать) проект.
3. Включить **Map Tiles API**:
   <https://console.cloud.google.com/apis/library/tile.googleapis.com>
4. Включить биллинг. Бесплатный уровень — 100 000 тайл-запросов в месяц;
   обычная сессия штаба укладывается с запасом.
5. **APIs & Services → Credentials** → **CREATE CREDENTIALS → API key**:
   <https://console.cloud.google.com/apis/credentials>
6. Открыть ключ, **Restrict key**:
   - **Website restrictions** → добавить `http://localhost:3000/*` и твой
     продакшен-домен, иначе Google откажет cross-origin.
   - **API restrictions** → только **Map Tiles API** (минимум привилегий).
7. В `.env`:
   ```env
   NEXT_PUBLIC_GOOGLE_3DTILES_KEY=AIzaSy...
   ```
8. Пересобрать: `npm run build && npm start`.

## Как проверить что подхватилось

Открой ГЕО, посмотри на кнопку **РЕАЛИЗМ** в панели управления:
- `РЕАЛИЗМ · esri` — ключей нет, используем Esri.
- `РЕАЛИЗМ · ion` — подхвачен Cesium Ion.
- `РЕАЛИЗМ · google` — подхвачен Google 3D-tiles (приоритет).

Нажмёшь кнопку — реализм включится и будет виден прямо на глобусе.

## Ничего не ломается без ключей

Отсутствие ключа — не ошибка. ГЕО всегда отвечает Esri + вся живая
визуализация (рейсы / спутники / землетрясения / циклоны / МКС / пуски /
дата-центры / плотины / вулканы / камеры / labels) работает одинаково в
любом тире реализма. Ключи — чистый upgrade качества картинки.
