# Meta Architectural Authority — устав управлений (27 этажей)

Единый источник для сборки «этаж за этажом». Составлен по ТЗ
`TZ_MetaArchitectural_FULL.md` (первое ТЗ Office3D/AEGIS входит в него как Часть II)
и подтверждён владельцем (MECHTATEL) в интервью 2026-10-05.

## Несущая рамка (не изменяется, §0 / Часть IV)

Законная ИИ-организация авторизованного пентеста и оборонной кибербезопасности.
- Активные действия — только по авторизованным целям (свои активы / договор /
  bug bounty в scope / свой полигон). Пока владелец не дал подписанный scope —
  **только свой полигон/свои активы**.
- Scope Enforcement — постоянное ядро, fail-closed (действие вне активного
  подтверждённого scope технически невозможно).
- Без автономной генерации вредоносного кода; PoC — только в лаборатории/в scope.
- Без атак на третьих лиц, без hack-back, без вторжения в чужие системы, без
  дезинформации/компромата, без подчистки следов на чужих системах. Наступательные
  протоколы против третьих лиц — **не реализуются** (§19.БИС).
- Внешние сообщения отправляет только человек. Полный неизменяемый аудит.
- Governance RULE_0…RULE_5 — в системном промпте каждого агента.

## Командная вертикаль

```
MECHTATEL (владелец)
   │
AM7 — верховная AI-сущность (оркестратор, единый центр; вето, мгновенная остановка)
   │
Шеф управления ×26
   │
Агенты-эксперты (16 на управление; СБ — усиленный штат)
```

Доклады снизу нормализуются и доходят до MECHTATEL только через AM7; прямой доступ
к владельцу — только у AM7. Межуправленческая операция — по санкции AM7 (§26).

## Кабинет AM7 и совещания

- Премиум-зона: длинный стол, AM7 во главе, 26 шефов вокруг, большой экран за
  спиной AM7 — живая сводка этажей (метрики/карта операций/инциденты), меняется
  под тему текущего докладчика.
- Расписание: ежедневное **09:00** (все шефы) + вечернее подведение итогов **21:00**
  + экстренные (по инциденту/тревоге, мгновенно, со звуком тревоги) + оперативные
  по ситуации + один-на-один с шефом. По часам штаба (местное время владельца).
- Голоса: каждый шеф докладывает своим голосом (над чем работает этаж, находки по
  критичности, статус агентов, инциденты); AM7 отвечает голосом и ставит задачи.
  Содержание — из реального состояния платформы; живой язык поверх фактов — когда
  подключим LLM (Ollama).
- Объявление — **только голосом** «Системы штаба» (мощно, в стиле закрытой
  AI-структуры), уведомляет всех; текста на экране нет; шефы собираются у стола;
  на этаже шефа — визуальный вызов без слов; лифт — когда будет башня.
- Усиления: авто-саммари каждого совещания в Архив (append-only); решения→задачи
  уходят на этажи и на доску задач; протокол «Кулак» (все ресурсы на одну задачу).

## Единый движок и порядок сборки

Один переиспользуемый движок на все этажи (агент-рантайм + Архив-память +
оркестратор + 3D-комнаты + сквозные сервисы scope/egress/аудит/kill-switch).
Новый этаж = конфигурация того же организма, движок не переписывается.

Строим сверху вниз, по одному этажу полностью (I.5): **27 (AM7+фундамент) → 26 →
25 → 24 → …**. «Этаж готов» = шеф + агенты + знания Архива + комната в 3D +
инструменты в sandbox + scope/аудит/kill-switch + тесты + Production Readiness
Review. На каждом гейте — стоп и показ владельцу.

Бэкенд живёт в `platform/`. Модель для разработки — Ollama (локально).
3D-башня (27 этажей, лифт, drill-down, The Gate) и ребрендинг в «Meta Architectural
Authority» — отдельными проходами позже. У каждого этажа свой интерьер под его
направление, общий стиль — как у текущего зала.
